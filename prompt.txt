## Strict AI Agent Design & Engineering Guidelines

### 1. Mobile-First Architecture

* **Base-Up Styling:** Write all base styles for small mobile viewports (`320px` to `480px`) first, then scale layouts progressively upward using `min-width` breakpoints (`sm: 640px`, `md: 768px`, `lg: 1024px`, `xl: 1280px`).
* **Touch & Ergonomics:** Enforce a minimum tap target of `48px × 48px` for all interactive elements, buttons, and links. Use fluid typography via CSS `clamp()` so headings scale smoothly without horizontal overflow on mobile screens.
* **Adaptive Stacking:** Render single-column vertical stacks with swipeable cards on mobile viewports, expanding into asymmetric bento grids and multi-column layouts only on tablet and desktop breakpoints.
